# Lab 7: EDA and Dataset Preparation

Explore raw sensor data, identify data-quality problems, and prepare a clean,
reproducible dataset for the machine-learning labs that follow.

## Objectives

In this lab, you will:

- inspect the structure and statistical properties of raw sensor data;
- detect missing values, outliers, class imbalance, drift, and inconsistent samples;
- document each cleaning and transformation decision; and
- create reproducible training, validation, and test splits.
